# Art sources

Every image in this folder is a **placeholder generated by `tools/gen_assets.py`**: procedural
shapes (mirror, rays, ripples, lens, phone, bands) screened into a one-colour 45° halftone. None is
taken from another work.

| File | Subject | Source |
|---|---|---|
| `mirror-*.webp` | Obsidian mirror disc with a frame and a highlight | generated |
| `rays-*.webp` | Light rays from a point | generated |
| `pool-*.webp` | Concentric ripples on water | generated |
| `lens-*.webp` | Lens rings | generated |
| `phone-*.webp` | Phone silhouette | generated |
| `bands-*.webp` | Wave bands | generated |
| `demo-backdrop.webp` | Ripples and rays, wide | generated |

`-signal` files are Signal ink on Paper, `-paper` files are Paper ink on Signal.

To replace one (DESIGN.md section 8): take a public-domain engraving (pre-1900, or a museum
open-access collection), convert it to grayscale, run it through the same halftone step, keep the
file name, and add a row here with the title, artist, date, collection and URL.
